为什么设计 Gate？
Stage 1 完成后 AI 主动暂停，让你在 投入更多算力前 确认方向。 避免 AI 沿着错误理解一意孤行跑完三个阶段。
✋
决策权永远在人手里
通过 → AI 继续；拒绝 → 终止任务；修改意见 → 带上批注重跑。 不是 prompt in / code out 的黑盒。
